# CardNova

E-Business card platform — NFC & QR powered digital profiles.

## Project structure

```
CardNova/
  server/     Express API (auth, cards, leads)
  client/     React + Vite + Tailwind frontend
```

## 1. Prerequisites

- Node.js 18+ and npm — https://nodejs.org
- Git — https://git-scm.com
- VS Code — https://code.visualstudio.com
- A free MongoDB Atlas account — https://www.mongodb.com/cloud/atlas/register

## 2. Set up the database

1. Create a free M0 cluster on MongoDB Atlas.
2. Under **Database Access**, create a database user with a username/password.
3. Under **Network Access**, allow your current IP (or `0.0.0.0/0` for development).
4. Under **Connect > Drivers**, copy your connection string — it looks like:
   `mongodb+srv://<username>:<password>@<cluster>.mongodb.net/`

## 3. Backend setup

```bash
cd server
npm install
cp .env.example .env
```

Open `.env` and fill in:
- `MONGO_URI` — the connection string from step 2 (add `cardnova` as the database name before the `?`)
- `JWT_SECRET` — generate one with `node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"`

Start the server:
```bash
npm run dev
```
Visit `http://localhost:5000/health` — you should see `{"status":"ok"}`.

## 4. Frontend setup

```bash
cd client
npm install
cp .env.example .env
npm run dev
```
Visit `http://localhost:5173` to see the CardNova frontend.

## 5. Push to GitHub

```bash
cd CardNova
git init
git add .
git commit -m "Initial CardNova project setup"
git branch -M main
git remote add origin https://github.com/<your-username>/cardnova.git
git push -u origin main
```

## What's wired up already

- Express server with MongoDB connection, JWT auth (register/login), and card CRUD routes
- Free-plan 2-card limit enforced server-side in `cardController.js`
- Mongoose models matching every field in the Create Card wizard
- React frontend with Home, About, Sign Up/In, and the full Dashboard (card wizard, sharing, QR preview, analytics, leads, billing)

## What's still a placeholder

- The frontend isn't calling the API yet — it runs on local mock state (next step)
- File uploads (photo/banner/PDF) aren't connected to real storage yet
- QR codes are a visual placeholder, not generated by the `qrcode` package yet
- Private-card access checks (invite email / access code / private link) aren't enforced server-side yet

We'll wire these up one at a time, in the order from the roadmap.
